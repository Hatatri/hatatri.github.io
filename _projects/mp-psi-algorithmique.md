## Présentation

Ressources d'algorithmique pour la seconde année de classes préparatoires (MP) :
cours, notebooks Jupyter et exercices, conçus pour préparer les épreuves
d'informatique des concours.

## Utilisation

1. Cloner le dépôt : `git clone https://github.com/Hatatri/MP-PSI-Algorithmique.git`
2. Ouvrir les notebooks avec Jupyter (ou directement sur
   [Elprepa](https://elprepa.online)).
